## Project Goal

Personal resume website for Nicholas Bradford (AI & Analytics Professional, @Salesforce, ex-Amazon) with a downloadable .docx resume. Hosted on GitHub Pages.

## Tech Stack

- Vanilla HTML5 + CSS3, no JavaScript
- Google Fonts: Playfair Display (headings) + Source Sans 3 (body)
- `python-docx` (Python 3) for generating the Word document
- GitHub Pages for hosting (static files from `main` branch, root `/`)

## Commands

- **Generate .docx:** `python3 scripts/generate-docx.py` (outputs to `assets/resume.docx`)
- **Local preview:** `python3 -m http.server 8080` then visit `localhost:8080`

## Structure

- `index.html` — single-page resume site (editorial data-viz aesthetic, timeline layout)
- `styles.css` — all styling (navy/teal/amber palette, responsive, print-friendly via `@media print`)
- `favicon.svg` — SVG favicon (NB initials)
- `assets/resume.docx` — downloadable Word document (generated by script)
- `scripts/generate-docx.py` — Python script to produce the .docx
- `plans/` — project plans and notes

## Design Decisions

- **Color palette:** Navy (#132743) for trust/authority, teal (#0D9488) for accents, amber (#F59E0B) for CTAs — based on persuasion psychology
- **Layout:** Timeline with dots/lines for experience section; skill chips instead of bullet lists; education cards with teal left-border
- **Print:** `@media print` block strips colors/backgrounds for clean PDF output via Ctrl+P; hides download button and footer
- **Accessibility:** Semantic HTML, ARIA labels, focus-visible outlines, sufficient contrast ratios
